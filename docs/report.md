## Данные и качество

Проверены 4 полных CSV. Обе части свойств содержат суммарно 20 275 902 строки.
После удаления 460 точных дублей осталось 2 755 641 событие; в дереве 1669 категорий.
Исторический каталог содержит 382 599 товаров. Исключены 173 282 просмотра товаров,
неизвестных на дату снимка. Срезов по размеру для обучения не применялось.

| Выборка | Просмотры | Покупки | Доля покупок |

| Validation | 460 232 | 5 463 | 0,011870 |

Победитель выбран по validation Average Precision: **0,0293304**.
Параметры всех трёх моделей, seed, библиотеки и контрольные суммы — в
[manifest модели](evidence/model-manifest.json).

| Метрика test | Модель | Константный baseline |
|---|---:|---:|
| Average Precision | 0,0243904 | 0,0111961 |
| Log loss | 0,0594907 | 0,0616738 |
| Brier | 0,0110212 | 0,0110770 |

Baseline использует частоту покупки на train. Улучшение есть, но абсолютная AP
невысока. На графике калибровки верхние интервалы переоценивают вероятность покупки.
Test используется только для финальной оценки.
[PR-кривая и калибровка](evidence/offline-quality.png) построены на test.

Модель использует исторический неизменный каталог без персонализации. Это базовый
вариант для согласованности train/serving и исключения будущих признаков.
Данные 2015 года, неизвестные товары и устаревание снимка ограничивают применение
на современном трафике. Мониторинг score не заменяет измерение качества по исходам.

## Ограничения

- Фиксированный каталог 2015 года без персонализации; неизвестные товары дают 404.
  Онлайн-качество без фактических покупок не измеряется.
- Одна реплика Kubernetes, Recreate с перерывом, доступ через port-forward;
  нет HA, публичного ingress, TLS/API-auth и промышленного SLA.
- Алерты доступны в Prometheus/Grafana; внешняя рассылка не настроена.
- TTL ВМ — 5 часов. Резервные копии сохранены вне ВМ; восстановление проверено
  на существующей ВМ, создание новой ВМ отдельно не тестировалось.
